
# 📊 SQL & Python Sales Analysis

A complete end-to-end Sales Data Analysis project using **MySQL** and **Python**. This project demonstrates how raw sales data can be transformed into meaningful business insights using SQL queries and Python-based exploratory data analysis.

---

## 📌 Project Overview

The objective of this project is to analyze a retail sales dataset and answer real-world business questions using SQL and Python.

The project includes:

- Data import into MySQL
- Database creation
- Data analysis using SQL
- Exploratory Data Analysis (EDA) using Python
- Business insights from sales, profit, products, and regions

# SQL Analysis

The SQL project answers several business questions such as:

### 1. Top 10 Revenue Generating Products

Identify the products generating the highest sales revenue.

### 2. Top 5 Selling Products in Each Region

Find the best-performing products region-wise using Window Functions.

### 3. Month-over-Month Sales Comparison

Compare monthly sales between 2022 and 2023.

### 4. Highest Sales Month for Each Category

Determine which month generated the maximum sales for every product category.

### 5. Highest Profit Growth by Sub-Category

Analyze which sub-category experienced the highest profit growth from 2022 to 2023.
